# **Requisitos y Rendimiento**

Para garantizar una experiencia fluida, rápida y estable al procesar grandes volúmenes de documentos tributarios electrónicos (DTE) y generar los libros de IVA, asegúrate de que tu equipo cumpla con los siguientes requisitos.

---

## **Compatibilidad de Sistemas Operativos**

PyConta es compatible con las principales plataformas de escritorio:

| Sistema Operativo | Versiones Compatibles | Arquitecturas Soportadas |
|---|---|---|
| **Windows** | Windows 10 (64-bit), Windows 11 | x64 (64 bits) |
| **macOS** | macOS 12 (Monterey), macOS 13 (Ventura), macOS 14 (Sonoma), macOS 15 (Sequoia) | Apple Silicon (M1, M2, M3, M4) e Intel (x86_64) |

---

## **Requisitos de Hardware**

| Componente | Requisito Mínimo | Requisito Recomendado |
|---|---|---|
| **Procesador (CPU)** | Intel Core i3 / AMD Ryzen 3 (1.5 GHz o superior) | Intel Core i5 / AMD Ryzen 5 o Apple Silicon (M1/M2/M3/M4) |
| **Memoria RAM** | 8 GB | 16 GB o superior (ideal para miles de DTEs por mes) |
| **Almacenamiento** | 500 MB libres en disco para la aplicación | 2 GB o más en disco SSD para almacenar historial de DTE y libros de IVA |
| **Resolución de Pantalla** | 1366 &times; 768 píxeles | 1920 &times; 1080 (Full HD) o superior para visualización cómoda de tablas |

---

## **Conectividad a Internet**

PyConta requiere conexión a internet para las siguientes operaciones:

- **Autenticación y Licencias**: Verificación de credenciales y activación de planes.
- **Descarga de Correos**: Conexión segura con proveedores de correo (Gmail, Microsoft Outlook, servidores IMAP).
- **Consulta en Hacienda**: Comunicación con el servicio de consulta oficial del Ministerio de Hacienda.
- **Sincronización de Datos**: Envío seguro de metadata y respaldos.

!!! tip "Recomendación de Velocidad"
    Para operaciones cotidianas, una velocidad de conexión de **10 Mbps** es suficiente. Si procesas descargas masivas o administras múltiples empresas con cientos de DTEs mensuales, se recomienda una conexión de **50 Mbps o superior**.
